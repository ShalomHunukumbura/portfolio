    payhere-sim

    PayHere payments testing, on PyPI

    Sends correctly signed PayHere payment notifications to localhost and checks a webhook handler against 10 scenarios: forged, underpaid, duplicate, late and simultaneous. Caught a race that granted 500 credits for one payment in a handler that passed manual testing.

  5. 05

    alembic-guard

    Migration linter for PostgreSQL, on PyPI

    Catches Alembic migrations that lock Postgres tables or break running code before they reach production. Parses migrations with Python's ast (never executes them), ships 10 rules with suggested fixes, and runs as a CLI or a GitHub Action that annotates pull requests.

    • Python
    • Alembic
    • PostgreSQL
    • AST
    • GitHub Actions
    • PyPI
    GitHub ↗ PyPI ↗ Marketplace ↗ Live demo PR ↗
  6. 06

    DocSage

    RAG from first principles, no LangChain

    Question answering over 37 engineering documents with cited answers. Hybrid retrieval (FAISS embeddings + BM25, merged with reciprocal rank fusion) puts the right document first for 93% of questions vs 86% for either alone, measured on a 54-question eval set. Refuses off-topic questions instead of guessing.

    • Python
    • FAISS
    • BM25
    • FastAPI
    • LLM
    • Docker
